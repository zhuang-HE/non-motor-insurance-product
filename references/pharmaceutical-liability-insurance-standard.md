# 药品责任保险条款及服务规范团体标准

> 来源：T/GDCCA XXXX—2025《药品责任保险条款及服务规范》（征求意见稿）
> 发布机构：广东省认证认可协会、广东省生物医药创新技术协会
> 起草单位：中国太平洋财产保险股份有限公司广东分公司、中国大地财产保险股份有限公司营业部、华泰保险经纪有限公司等

## 一、标准概述

### 1.1 制定背景

药品责任保险是保障生物医药产业稳健发展的重要风险管理工具。面对该保险市场发展初期的现状，建立一套业界共识的、统一的保险条款与服务规范，成为引导行业迈向规范化与成熟化的关键举措。

本标准致力于为保险产品的供给树立标杆，为生物医药企业选购保险提供明确指导，并为相关方的监督与评审工作提供专业依据。最终通过促进保险行业与生物医药行业的深度融合与战略协同，为我国生物医药产业的创新与高质量发展保驾护航。

### 1.2 适用范围

本文件规定了**临床试验责任保险**与**药品上市许可持有人责任保险**的保险保障要求、服务实施要求。

适用于：
- 保险公司
- 保险经纪公司
- 第三方管理机构（TPA）
- 临床研究组织（CRO）
- 药企申办者
- 研究者申办（IIT）
- 药品上市许可持有人及其境内责任人

在中国境内开展的临床试验及相关保险活动，并为临床试验伦理委员会和相关机构评估保障能力与风险承担能力提供参考，**亦可供医疗器械相关责任保险参照使用**。

## 二、核心术语和定义

### 2.1 临床试验 (Clinical Trial)

以人体（患者或健康受试者）为对象的试验，意在发现或验证某种试验药物的临床医学、药理学以及其他药效学作用、不良反应，或者试验药物的吸收、分布、代谢和排泄，以确定药物的疗效与安全性的系统性试验。

### 2.2 申办者 (Sponsor)

负责临床试验的发起、管理和经费安排的个人、公司、机构或组织。

### 2.3 药品上市许可持有人 (Marketing Authorization Holder, MAH)

取得药品注册证书，以自己的名义将药品投放市场，并对药品全生命周期承担相应责任的企业或者药品研制机构等主体。

### 2.4 临床试验参与者/受试者 (Subject)

自愿参加临床试验的个人，预期将接受试验药物或作为对照组（使用对照药或安慰剂），包括患者、健康人。

### 2.5 伦理委员会 (Ethics Committee)

由医学专业人员和非医学人员组成的独立机构，其职责是通过对试验方案、研究者资质、设施以及获取和记录试验参与者知情同意的方法和材料进行审查和批准/提供同意意见，确保人类试验参与者的权益、安全和福祉受到保护。

### 2.6 责任保险 (Liability Insurance)

以被保险人对第三者依法应负的赔偿责任为保险标的保险。

### 2.7 临床试验责任保险 (Clinical Trial Liability Insurance)

以申办者、研究者、临床试验机构等因开展临床试验造成临床试验参与者试验相关损害而应承担的赔偿责任为保险标的的保险。

### 2.8 持有人责任保险 (MAH Liability Insurance)

以药品上市许可持有人因其上市药品造成患者人身伤害或财产损失而应承担的赔偿责任为保险标的的保险。

### 2.9 每次事故 (Per Accident/Per Occurrence)

因同一不良反应导致多名使用者遭受人身损害，并在保险期间内同时或先后向被保险人提出属于保险责任范围内的一项或一系列索赔或民事诉讼，此类情况视为一次保险事故。

### 2.10 可疑且非预期严重不良反应 (SUSAR)

临床表现的性质和严重程度超出了试验药物研究者手册、已上市药品说明书、产品特性摘要等现有资料所载信息的反应。

**SUSAR判定标准（三要素）**：
- 严重性：导致死亡/危及生命/需住院治疗/永久或严重残疾/先天性异常
- 非预期性：超出研究者手册/说明书/产品特性摘要所载信息
- 因果关系：与药品存在合理因果关联

### 2.11 追溯期 (Retroactive Date)

保险合同列明的一个特定日期（称为追溯日期）之后至保险期间开始之日的连续时段，在该时段内被保险人开展业务活动并出现符合本合同索赔条件的保险事故，保险人按照保险合同的约定承担赔偿责任。

## 三、资质与要求

### 3.1 保险人（保险公司）要求

| 序号 | 要求 | 说明 |
|-----|------|-----|
| a) | 赔付能力 | 保证有足够的赔付能力，持续满足监管机构偿付能力标准 |
| b) | 风险评估能力 | 能在投保前对临床试验项目及持有人责任风险做出评估，并合理定价 |
| c) | 风险管理能力 | 具备专业的风险管理能力，能够提供全流程风险预防建议和事故应对支持 |
| d) | 理赔服务能力 | 能够提供专业的理赔服务，指定专业人员全程负责、直接面对受试者/患者及时开展理赔 |
| e) | 外溢风险关注 | 能够关注被保险人对临床试验项目及持有人声誉的关注，及时回应各方关切 |
| f) | 时效保证 | 能够确保赔案处理的专业性与时效性 |
| g) | 查询服务 | 能够提供及时的赔偿案件进度查询服务，确保流程透明、可追溯 |

### 3.2 被保险人要求

| 序号 | 要求 | 说明 |
|-----|------|-----|
| a) | 主体资格 | 被保险人为临床试验的申办者或持有人且具备合法的主体资格，能够独立承担民事责任 |
| b) | 如实告知 | 保证如实告知与投保相关的全部信息，确保临床试验项目资料的真实、完整、准确 |
| c) | 合规能力 | 有合法合规开展临床试验的能力，确保受试者权益得到充分保护 |

### 3.3 保险经纪要求

| 序号 | 要求 | 说明 |
|-----|------|-----|
| a) | 诚信经营 | 能够坚持诚信、合法经营，遵守生物医药行业的合规要求 |
| b) | 专业资质 | 具备专业资质，熟悉临床试验风险管理、持有人风险管理及保险产品特性 |
| c) | 沟通桥梁 | 能够担当被保险人与保险公司之间的翻译者角色，准确传递双方信息 |
| d) | 客观分析 | 能够基于保障范围、理赔规则、多边服务、保费价格等维度对保险人提供的方案进行客观分析与比较 |

### 3.4 第三方独立评估人要求

| 序号 | 要求 | 说明 |
|-----|------|-----|
| a) | 组织性质 | 为依然成立的公益性或商业性法人组织，主营业务包括药物安全性评价或资助受到严重药品不良事件伤害的患者等相关工作 |
| b) | 资质认可 | 获得保险人与被保险人对其资质的认可 |
| c) | 专业资质 | 具备相应专业资质，包括医学、药学、法律及保险等领域知识 |
| d) | 专家团队 | 专家团队有副高级及以上职称人员或具备同等资格专家 |
| e) | 因果分析 | 能够客观、公正地对临床试验或上市后药品使用相关损害事件进行因果关系分析与责任认定 |
| f) | 现场调查 | 能够在损害事件发生后及时介入，直接面对受试者/患者及其家属，开展现场调查与证据收集 |

## 四、保险保障要求

### 4.1 临床试验责任保险

#### 4.1.1 风险评估要求

| 评估维度 | 具体要求 |
|---------|---------|
| 评估时机 | 在承保前对保险标的的风险进行评估 |
| 分类评估 | 需要按照已知风险和不可预见的风险（如SUSAR）**分别评估**其可能性与危害程度 |
| 区别定价 | 保险的承保报价需要按照已知风险与SUSAR事件进行**区别定价** |

#### 4.1.2 责任界定

| 要点 | 说明 |
|-----|------|
| 产品性质 | 临床试验责任险属于**财产险**，而非健康险，需在知情同意书等文件中准确描述该保障的性质 |
| 核心功能 | 转移临床试验申办者在临床试验中因责任导致的经济风险（如临床试验参与者伤害赔偿责任） |
| 责任承担 | 申办者依法需要承担的赔偿责任，由保险人负责承担 |
| 理赔前提 | 确认相关责任由申办者承担 |

#### 4.1.3 理赔准则

| 序号 | 准则 | 说明 |
|-----|------|-----|
| a) | 因果关系判断 | 如果与试验用药品或试验操作有关则考虑赔付 |
| b) | 因果分类 | 包括二分类评价的"有关"，也包括五分类/六分类评价结果中的**肯定有关、可能有关、很可能有关、不能排除** |
| c) | 全额赔付 | 当评估为"有关"时则考虑**全额赔付SAE治疗的相关费用**，避免临床试验参与者支付额外费用 |
| d) | 第三方评价 | 寻求无利益冲突的第三方评价意见，以该独立第三方评价的因果关系为准 |
| e) | 死亡赔偿例外 | 对于从试验中有获益的患者，如获得较好的治疗效果但最终因SAE死亡，一般**不建议赔付死亡赔偿金** |
| f) | 知情同意约定 | 对于应由申办者承担的责任但不属于保险赔付事项，需在知情同意书等文件中明确该类补偿的原则、责任承担方及途径 |

#### 4.1.4 主险条款示范

> 在保险期间或保险单载明的追溯期内，被保险人在开展经政府有关部门或伦理委员会批准实施的被保险临床试验活动过程中出现**可疑且非预期严重不良反应（SUSAR）**，造成临床试验参与者遭受人身伤亡，由受害人或其代理人在保险期间内首次向被保险人提出索赔，依照中华人民共和国法律（不含港澳台地区法律）应由被保险人承担的经济赔偿责任，保险人按照本合同的约定负责赔偿。

#### 4.1.5 附加险条款示范

> 在保险期间或保险单载明的追溯期内，临床试验参与者在参加主险合同载明的临床试验过程中，因发生不良事件/不良反应导致临床试验参与者遭受人身伤亡，由临床试验参与者或其代理人在保险期间内首次向被保险人提出损害赔偿请求，对被保险人向临床试验参与者支付的损害补偿金，保险人根据主险及本附加险合同的约定承担赔偿责任。

#### 4.1.6 责任免除

**免除情形**：
| 序号 | 情形 |
|-----|------|
| a) | 临床试验未经国家药品监督管理局及其他相关管理机构、伦理委员会批准或批准后被撤销、或批件已过有效期 |
| b) | 参与临床试验的临床试验机构、研究者不具备相应资质 |
| c) | 临床试验在中华人民共和国境外（含港澳台地区）实施 |
| d) | 被保险人违反GCP、GVP等规定 |
| e) | 研究者偏离或违反伦理委员会已经批准的试验方案导致损害 |

**免除原因**：
| 序号 | 原因 |
|-----|------|
| a) | 投保人、被保险人或其雇员、代表的故意行为、重大过失行为、违法犯罪行为 |
| b) | 被保险人或临床试验机构执行与被保险临床试验无关的诊疗或其他行为 |
| c) | 医疗事故、医疗过错、诊疗意外 |
| d) | 行政行为、司法行为 |
| e) | 试验用药品/器械未达预期效果 |
| f) | 试验用药品/器械存在质量问题 |
| g) | 在临床试验结束后继续使用试验用药品/器械 |
| h) | 临床试验参与者即使不参与被保险临床试验仍会发生的人身伤亡或健康恶化 |

**免除损失**：
| 序号 | 损失 |
|-----|------|
| a) | 被保险人根据与他人签订的协议应承担的责任（但即使没有这种协议，被保险人依法仍应承担的责任不在此限） |
| b) | 投保人、被保险人在投保时知道或应当知道的索赔 |
| c) | 临床试验参与者以外其他人员的人身伤亡 |
| d) | 保险单中载明的免赔额或按保险单载明的免赔率计算的免赔额 |
| e) | 《知情同意书》约定的被免于索赔或免除的责任和费用 |

### 4.2 持有人责任保险

#### 4.2.1 风险评估要求

| 评估维度 | 具体要求 |
|---------|---------|
| 评估时机 | 在承保前对保险标的进行风险评估 |
| 全面覆盖 | 评估涵盖已知风险、潜在风险及未知风险（如非预期严重不良反应） |
| 分类评估 | 按照已知风险和不可预见的风险（如SUSAR）分别评估其可能性与危害程度 |
| 区别定价 | 按照已知风险与SUSAR事件进行区别定价 |

#### 4.2.2 责任界定

| 要点 | 说明 |
|-----|------|
| 产品性质 | 药品上市许可持有人责任险属于**财产险**范畴 |
| 核心功能 | 转移药品上市许可持有人在药品上市后因**药品质量问题、不良反应或说明书缺陷**等导致的民事赔偿责任风险 |
| 保障范围 | 因使用药品导致药品使用者遭受的人身伤害或财产损失，对于持有人依法承担的经济赔偿责任，保险公司负责承担 |

#### 4.2.3 理赔准则

| 序号 | 准则 | 说明 |
|-----|------|-----|
| a) | 因果关系赔付 | 若不良事件经认定与药品使用存在因果关系（包括**肯定有关、可能有关、很可能有关或无法排除关联**），则相关医疗费用、残疾补偿及合理抚慰金应予以赔付 |
| b) | 第三方评价 | 寻求无利益冲突的第三方评价意见，以该独立第三方评价的因果关系为准 |
| c) | 不赔付情形 | 对于药品未达期望的疗效（即药物无效）、或损害并非因药品责任所致的情况，原则上**不予承担死亡或非治疗性赔偿金** |

#### 4.2.4 主险条款示范

> 在保险期间或保险单载明的追溯期内，因保险单载明的药品出现**可疑且非预期严重不良反应（SUSAR）**，导致药品使用者遭受人身伤亡，由受害人或其代理人在保险期间内首次向被保险人提出索赔，依照中华人民共和国法律（不包括香港、澳门特别行政区和台湾地区法律）应由被保险人承担的经济赔偿责任，保险人按照本合同的约定负责赔偿。

#### 4.2.5 附加险条款示范

> 在保险期间或保险单载明的追溯期内，因保险单载明的药品出现**药品不良反应**导致使用者遭受人身伤亡，由受害人或其代理人在保险期间内首次向被保险人提出损害赔偿请求，对被保险人向受害人支付的损害补偿金，保险人根据主险及本附加险合同的约定承担赔偿责任。

#### 4.2.6 责任免除

**免除情形**：
| 序号 | 情形 |
|-----|------|
| a) | 被保险药品在生产、销售前未获药品上市许可及药品批准文号，或已超过药品注册批件有效期 |
| b) | 受托生产的药品生产企业无《药品生产许可证》或受托销售的药品经营企业无有效的《药品经营许可证》 |
| c) | 持有人或受托生产企业违反GMP、GVP等相关监管规定 |
| d) | 药品已被药品监督管理部门宣布暂停销售使用或要求召回 |
| e) | 销往中华人民共和国境外（含港澳台地区）的药品 |

**免除原因**：
| 序号 | 原因 |
|-----|------|
| a) | 投保人、被保险人或其雇员、代表的故意或重大过失行为、犯罪行为 |
| b) | 医疗事故、医疗过错、诊疗意外 |
| c) | 行政行为、司法行为 |
| d) | 药品使用者的不当使用（超保质期、未遵医嘱、违反说明书规定） |
| e) | 投保人、被保险人在投保时知道或应当知道的索赔 |

**免除损失**：
| 序号 | 损失 |
|-----|------|
| a) | 被保险人根据与他人签订的协议应承担的责任（但即使没有这种协议，被保险人依法仍应承担的责任不在此限） |
| b) | 药品使用者以外其他人员的人身伤亡 |
| c) | 药品本身的损失或其退换、回收、召回、销毁或其他处置引起的损失或费用 |
| d) | 保险单载明的药品作为其他药品、医疗制品的原材料、组成部分时导致其他药品、医疗制品的损失 |
| e) | 保险单中载明的免赔额或按保险单载明的免赔率计算的免赔额 |

## 五、保费定价原则

### 5.1 分类定价原则

#### 5.1.1 不良事件/预期不良反应

| 要点 | 说明 |
|-----|------|
| 定义 | 药品说明书、研究者手册或产品特性摘要等已有资料中已明确记载的、已知性质和发生程度的不良反应 |
| 定价方法 | 其风险概率和损失幅度可基于历史数据进行分析和预测，采用**经验费率法**进行定价 |
| 费率参考 | 主要参考该产品的历史理赔数据、同类产品不良反应发生率及行业损失率数据进行厘定 |

#### 5.1.2 SUSAR（可疑且非预期严重不良反应）

| 要点 | 说明 |
|-----|------|
| 定义 | 同时满足"严重"、"非预期"且与药品存在合理因果关联的不良反应 |
| 风险特征 | 该类事件是药品安全风险的核心焦点，具有**低频高损**的特征，极易引发重大索赔和诉讼 |
| 定价方法 | 定价需采用**综合模型法**，在基准费率基础上，重点评估其导致群体性药害事件的潜在可能性、可能涉及的赔偿范围、法律环境变化以及媒体关注度等重大风险因子 |
| 附加要求 | 引入**显著风险附加**，实行差异化定价 |

### 5.2 风险对价原则

#### 5.2.1 临床试验责任保险风险因子

| 风险因子 | 说明 |
|---------|------|
| 项目所处分期 | I期/II期/III期，风险逐期降低 |
| 试验药物安全特征 | 安全性数据充分程度 |
| 对照药物安全特征 | 对照药已知安全性 |
| 临床试验参与者人数 | 受试者数量 |
| 试验周期 | 试验持续时间 |
| 临床试验参与者自身健康状况 | 健康受试者 vs 患者 |
| 试验流程与涉及的操作 | 侵入性操作程度 |
| 预期理赔情况 | 历史理赔数据 |

#### 5.2.2 上市后持有人责任保险风险因子

| 风险因子 | 说明 |
|---------|------|
| 药品安全特征 | 说明书载明不良反应数量与严重程度 |
| 特殊管理类别 | 如麻醉类药品等 |
| 药品使用人群 | 用药人群规模与特征 |
| 药品适应症范围 | 适应症数量与覆盖人群 |
| 药品市场销售规模及渠道分布 | 销售量与渠道复杂度 |
| 既往重大安全事件记录 | 历史SUSAR情况 |
| 既往理赔情况 | 历史赔付数据 |

#### 5.2.3 责任主体资质评估

| 评估维度 | 说明 |
|---------|------|
| 相关资质许可 | 生产/经营许可、药品注册批件 |
| 质量管理体系成熟度 | GMP认证等级 |
| 不良反应监测体系的完善程度 | PV体系建设 |
| 过往理赔记录 | 历史赔付情况 |
| 风险管理能力 | 风险管理水平 |
| 合规历史及现状 | 监管处罚记录 |

#### 5.2.4 业务规模

| 指标 | 说明 |
|-----|------|
| 上市后持有人责任险 | 预计年销售收入作为保费计算基础 |
| 临床试验责任险 | 预计临床试验参与者人数作为保费计算基础 |

#### 5.2.5 追溯期规定

追溯期长度作为评估**长尾风险**的重要依据。

### 5.3 限额与免赔匹配原则

#### 5.3.1 责任限额设置

| 要点 | 说明 |
|-----|------|
| 限额类型 | 累计责任限额、每次事故责任限额、每人责任限额 |
| 设置原则 | 根据投保人与保险人协商确定 |
| 合理原则 | 设置合理的责任限额，不宜过高或过低 |

#### 5.3.2 免赔设置

| 要点 | 说明 |
|-----|------|
| 免赔确定 | 根据协商确定的每次事故免赔额或免赔率进行定价 |
| 自留风险 | 投保人自留风险与保费水平负相关 |
| 科学匹配 | 限额与免赔需科学匹配，确保风险分担合理 |
| 避免零免赔 | 原则上避免零免赔，以免因过高的理赔管理成本增加投保人成本 |

### 5.4 剔除重大违规风险原则

报价时将必须由被保险人承担的重大违法、违规责任所致的损失排除在保险风险覆盖范围：

| 排除项目 | 说明 |
|---------|------|
| 无证生产/经营 | 合法资质是承保前提 |
| 严重违反质量管理规范 | GMP/GCP/GSP违规导致的损失 |
| 行政处罚 | 罚款及惩罚性赔偿 |
| 其他违法责任 | 故意行为、犯罪行为等 |

### 5.5 最低保费原则

为覆盖基本运营成本，保费设定时应考虑**最低（年）保费标准**，最终保险费不得低于该标准。

### 5.6 主附险搭配原则

| 原则 | 说明 |
|-----|------|
| 附加条件 | 附加险必须在投保相应主险的基础上附加，不重复计算主险已保障的责任范围 |
| 灵活扩展 | 通过附加险的保额、保费设计，实现风险保障的灵活扩展与精准匹配 |
| 费率公平 | 通过主险与附加险不同的费率设计，确保费率厘定的科学性、合理性和公平性 |

## 六、服务实施要求

### 6.1 服务机制

| 要求 | 说明 |
|-----|------|
| 专业标准 | 应由专业、标准的服务保证标准条款中承诺的保险保障责任得以清晰、准确、及时地兑现 |
| 多方共建 | 标准化服务体系应由多方共同构建：保险公司、保险经纪、第三方独立评估机构 |
| 全流程覆盖 | 标准化服务体系应覆盖：承保前的风险评估、保单生效后的风险减量管理、基于独立评估的理赔服务、外溢风险评估与管理以及服务能力的持续提升 |

### 6.2 承保准备风险评估

#### 6.2.1 风险信息收集

**临床试验责任险需提供**：
- 试验方案或摘要
- 知情同意书
- 研究者手册（如有）

**持有人责任险需提供**：
- 药品说明书或安全性概要
- 不良反应监测数据（如有）
- 上市后安全性研究（PASS）计划（如有）
- 既往赔偿或投诉记录（如有）

#### 6.2.2 风险识别与评估

| 评估维度 | 说明 |
|---------|------|
| 已知风险 | 评估应涵盖已知/可预见风险（如说明书或研究者手册已载明的不良反应） |
| 风险范围 | 评估应涵盖标的药物本身风险以及外溢风险的可能性 |
| 操作风险 | 评估应考虑试验设计、试验操作可能的风险 |
| 方案沟通 | 保险经纪人应能基于风险评估报告与被保险人进行保险方案的沟通 |

#### 6.2.3 设计承保方案与报价

| 要求 | 说明 |
|-----|------|
| 分类定价 | 应针对小风险（如AE）及低频大风险（如SUSAR）分别定价 |
| 数据参考 | 应参考行业数据及历史赔付情况计算保费 |
| 方案要素 | 承保方案应包括明确的保障范围、理赔规则、多边服务、保费价格 |
| 费率匹配 | 保费厘定应与保障范围、理赔规则、多边服务相匹配 |

#### 6.2.4 风险改善建议

为提高风险可控性，保险人可向被保险人出具**《风险管理建议书》**，提出针对性的风险管理措施。

### 6.3 保单生效后风险减量

#### 6.3.1 定期评估

| 评估内容 | 说明 |
|---------|------|
| 风险改善执行 | 保险人对被保险人执行风险改善建议的情况进行跟踪 |
| 管控效果 | 评估其风险管控措施的落地效果 |
| 风险趋势 | 通过分析赔案数据、风险趋势变化，评估整体风险管理服务的成效 |

#### 6.3.2 理赔服务要求

**临床试验责任险理赔材料**：
- 保单及投保凭证
- 临床试验批件/伦理委员会批件
- 试验方案、ICF、IB
- 损害证明材料
- 经被保险人药物警戒职能部门评估后的SAE/SUSAR报告

**持有人责任险理赔材料**：
- 保单及投保凭证
- 药品上市许可及药品批准文号
- 所涉药品的质量合格放行记录或追溯码信息
- 经被保险人药物警戒职能团队评估后的《不良事件报告表》
- 国家监测机构针对《不良事件报告表》的接收记录（ACK文件或国家系统中截图）

**理赔流程**：
1. 接到报案后，迅速启动调查程序
2. 由内部专职人员或委托独立第三方对事件的原因、损失程度、与药品的因果关系进行客观评估
3. 加强与受试者/患者或其家属的沟通
4. 依据保险条款及调查结果进行理赔审核
5. 及时支付赔款，确保患者及时获得经济补偿
6. 对已发生的赔案进行归档和根本原因分析

### 6.4 退保处理

| 处理原则 | 说明 |
|---------|------|
| 基本原则 | 保单效力终止前的退保处理应遵循规范、公平、清晰的原则 |
| 退保情形 | 协议退保、投保人申请退保及保险人依约解约 |

**退保费用计算**：
```
未满期保险费 = 应收保险费 ×（剩余保险期间天数/保险期间天数）×（累计责任限额－累计赔偿金额）/累计责任限额
```

其中"累计赔偿金额"包括保险期间内保险人已支付及已发生尚未支付的保险赔偿金（含法律费用）。

### 6.5 持续改进

| 改进维度 | 说明 |
|---------|------|
| 服务有效性评估 | 定期评估理赔服务流程的效率与质量，包括接报案响应时效、查勘调查的及时性与深度、损失理算的准确性 |
| 质量审核机制 | 建立内部质量审核机制，确保服务过程符合本标准、保险合同约定及相关法律法规要求 |
| 沟通与协同 | 保险人主动与被保险人、研究机构、医疗机构、监管机构、伦理委员会等保持密切沟通 |
